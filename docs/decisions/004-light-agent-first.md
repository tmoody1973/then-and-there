# 004 — A light personal agent first; a talk-to agent only if the light one proves itself

**Decision.** Build a "light" agent that remembers the places and names a user follows, works overnight, and sends at most one verified note. Start a chat-style agent only after the light one has run two nights untouched and delivered a real verified note, and no later than Mon Nov 2.

**Why this came up.** The original plan centered a persistent agent. But real "new page" finds are rare (about 20,000 new pages a month nationwide), and a talk-to agent is the riskiest thing to demo live.

**Options.**
1. **Light agent.** About a day of work; shows "it keeps working for you" safely.
2. **Talk-to agent.** Most impressive if it works; 2–3 days; most likely to break live.
3. **No agent.** Saves a day; loses the agent story and some of the Meta-tools score.

**What we chose and why.** Option 1, with Option 2 gated. Tarik chose it. The talk-to agent is built on top of the light one's tools, so nothing is thrown away. Its daily visible job, picking a "meanwhile, back home" story for the game, works every day even when no new pages arrive.

**What we gave up.** The chat agent may not make the demo. A live overnight find during demo week is unlikely, so the demo replays a recent real batch, labeled as a replay.

**How we'll know if this was right.** By Nov 2: two clean unattended nights, an activity log that matches reality, and one real verified note.
